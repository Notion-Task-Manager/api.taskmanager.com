

# Taskion

Taskion es una herramienta ligera de gestión de tareas que aprovecha las capacidades de Notion como base de datos backend.

# Motivación

La motivación detrás de Taskion es crear un gestor de tareas sencillo e intuitivo que aproveche el poder de Notion como base de datos. Este proyecto tiene como objetivo proporcionar una integración perfecta con Notion, permitiendo a los usuarios gestionar sus tareas y notas de una manera más organizada y eficiente. Al utilizar la API de Notion, Taskion busca ofrecer un enfoque único e innovador para la gestión de tareas, facilitando que los usuarios mantengan el control de sus tareas y proyectos.

# Stack Tecnológico

- Go
- Fiber
- Air (recarga en caliente)
- Dokploy (despliegue)
- Notion API

# Características
